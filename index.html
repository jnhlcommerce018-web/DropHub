Como Hospedar Gratuitamente no GitHub Pages

Atualize o DropHub existente sem criar um segundo site

1 Criar Repositório

Abra o repositório existente do DropHub no GitHub. Não crie outro repositório.

2 Criar Arquivo

No repositório existente, abra o arquivo index.html e escolha editar.

3 Colar o Código

Substitua o conteúdo do arquivo pelo HTML revisado e clique em Commit changes para publicar.

4 Ativar GitHub Pages

Se o GitHub Pages já estiver ativo, aguarde a publicação após o commit. Só configure Settings > Pages se o site ainda não estiver publicado.

O arquivo precisa obrigatoriamente se chamar index.html
